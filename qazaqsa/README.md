# Qazaqsa Cheesecake — 3D-сайт

Одностраничный сайт с 3D-тортами для **Qazaqsa Cheesecake** (Алматы).

## Что внутри

- **Заставка** — эмблема «арка + шаңырақ» рисуется линией, буквы QAZAQSA поднимаются, занавес раскрывается.
- **3D-герой** — фирменный чизкейк на золотой подложке. При скролле (или по нажатию на торт) он делает
  полный оборот на 360°, кусочек выезжает и показывает начинку, сбоку появляются подписи. Счётчик градусов в углу.
- **Меню из 17 позиций** — у каждого торта своя 3D-модель, процедурная, без внешних файлов: Oreo, Lotus, клубника,
  мёд, Kinder Bueno, Nutella, фисташка с катаифи и т. д. При наведении карточка наклоняется, а торт ускоряет вращение.
  Есть фильтр «Чизкейки / Торты» и выбор веса L/M.
- **Карточка торта** — большая 3D-модель, которую можно крутить пальцем или мышью, количество, «Заказать сразу».
- **Корзина** — количество, удаление, имя, дата, самовывоз/доставка, комментарий. Кнопка
  **«Заказать в WhatsApp»** открывает чат с номером `+7 771 533 03 63` и готовым текстом:

  ```
  Здравствуйте! Хочу заказать у вас торт 🍰

  1. *Қазақша чизкейк* (L · 1,5 кг) × 1 = 10 500 ₸
     Фото: https://…/assets/cakes/kazakh.jpg

  *Итого: 10 500 ₸*
  Имя: …   Дата: …   Получение: …   Комментарий: …
  ```
- **Языки RU / ҚАЗ**, микс-чизкейк с реальным фото, «Как заказать», галерея, FAQ, контакты с картой и 2ГИС,
  плавающая кнопка WhatsApp, мобильная панель корзины.
- Если WebGL недоступен, вместо 3D показываются заранее отрисованные картинки.

## Как изменить цены, контакты, тексты

Всё лежит в одном файле — **`js/data.js`**:

- `CONFIG` — номер WhatsApp, телефон, Instagram, адрес, часы работы, ссылка на 2ГИС;
- `PRODUCTS` — названия, веса, цены (`price: 10500`) и описания;
- `I18N` — все тексты интерфейса на русском и казахском.

## Как запустить локально

ES-модули не работают из `file://`, поэтому нужен любой локальный сервер:

```bash
cd qazaqsa
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Как опубликовать (бесплатно, GitHub Pages)

1. В репозитории на GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
2. Выберите ветку и папку `/ (root)`, нажмите **Save**.
3. Через минуту сайт будет по адресу `https://<логин>.github.io/<репозиторий>/qazaqsa/`.

Подойдёт любой статический хостинг (Netlify, Vercel, свой домен): просто загрузите папку `qazaqsa` целиком.

> Ссылки «Фото» в сообщении WhatsApp строятся от адреса сайта, поэтому работают только на опубликованном
> сайте (по http/https), а не при открытии файла с диска.

## Фото тортов

- `assets/cakes/<id>.webp` — картинки для корзины и запасного режима;
- `assets/cakes/<id>.jpg` — «фото», ссылка на которое уходит в WhatsApp.

Их можно заменить настоящими фотографиями с теми же именами файлов. Чтобы перерисовать картинки из 3D после
правок моделей, откройте `tools/render.html` через локальный сервер и нажмите «Скачать всё».

`assets/photos/` — реальные фото из Instagram (галерея и микс-чизкейк).

## Структура

```
index.html          разметка
css/style.css       стили
js/data.js          контакты, цены, тексты  ← редактировать здесь
js/app.js           интерфейс: заставка, скролл, меню, корзина, WhatsApp
js/stage.js         WebGL-сцена: герой, мини-сцены в карточках, модалка
js/cakes.js         процедурные 3D-торты (форма, шейдер, топпинги)
js/vendor/          three.js r180 (MIT)
tools/render.html   генератор картинок тортов
```
