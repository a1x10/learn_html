# STELLA — сайт персонального AI-агента

Лендинг с 3D-сценой и анимациями, а также регистрацией: код подтверждения приходит в WhatsApp, а заявка «Создать агента» — вам в Telegram.

## Что внутри

**3D и анимации**
- WebGL-сцена (Three.js): живое «нейроядро» с шейдерной деформацией и переливом, галактика из 16 000 частиц, туманность, орбитальные кольца с кометами, свечение (bloom).
- Процедурные 3D-модели на орбите: телефон с перепиской, SIM-карта, глобус, монитор, AI-чип, пузырь сообщения, документ. При наведении мыши модель увеличивается.
- Камера и ядро перемещаются при прокрутке. Ядро встаёт точно за нужный блок: телефон, карусель, консоль, орбиту, кнопку.
- 3D-телефон с живыми демо: STELLA торгуется в WhatsApp, звонит в клинику, парсит цены, управляет ПК.
- Буквы STELLA с объёмом, которые при прокрутке разлетаются в 3D. Флип-карточки «Что заменяет», 3D-карусель сценариев, орбита окружений, наклон карточек за курсором, магнитные кнопки, свой курсор, плавная прокрутка, прелоадер.
- Адаптив под телефон. Если устройство слабое, качество графики снижается автоматически.

**Регистрация** (открывается по любой кнопке «Попробовать», «Создать агента» или кнопке тарифа)
1. Имя, фамилия, «Откуда вы о нас узнали» (от друзей/коллег, через электронный портал, TikTok, Instagram, реклама в приложении)
2. Капча: пазл, его проверяет сервер. Можно включить Cloudflare Turnstile
3. Проверка браузера: WebGL, cookies, HTTPS, связь с сервером, экран, язык
4. Политика конфиденциальности и согласие
5. Загрузка
6. Номер телефона: 6-значный код приходит в **WhatsApp**
7. Выбор тарифа (FREE / PLUS / PRO / ULTRA)
8. Рассказ об агенте, имя агента и задачи, кнопка **«Создать агента»**
9. Вам в **Telegram** приходит заявка, а человек видит: «На ваш номер скоро отправят сообщение с инструкцией для запуска агента». Ему в WhatsApp тоже уходит подтверждение.

Пример сообщения в Telegram:

```

👤 Анна Смирнова
📱 +7 999 123-45-67 — ✅ подтверждён через WhatsApp

🤖 Имя агента: Нова
🧩 Задачи: Звонки голосом, Переписка в WhatsApp, Парсинг сайтов
📣 Откуда узнали: TikTok
🌐 Chrome 141 · Windows · Компьютер · ru-RU · 1920×1080 · Europe/Moscow

[💬 Написать в WhatsApp] [✈️ Telegram]
```

Все заявки также сохраняются в файл `data/registrations.jsonl`.

## Быстрый запуск

Нужен [Node.js](https://nodejs.org) версии 18.17 или новее. Устанавливать зависимости не нужно.

```bash
cd stella
cp .env.example .env
npm start
```

Откройте http://localhost:3000.

По умолчанию стоит `WA_PROVIDER=console`. Это режим проверки: код не отправляется в WhatsApp, а печатается в консоли сервера и показывается на экране регистрации. Так можно пройти всю регистрацию, ничего не настраивая.

## 1. Подключаем Telegram (сюда приходят заявки)

1. Откройте [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`. Придумайте имя — бот пришлёт **токен**.
2. Вставьте токен в `.env`: `TELEGRAM_BOT_TOKEN=123456:ABC...`
3. Найдите своего бота в Telegram и нажмите «Старт».
4. Выполните `npm run chat-id`. Команда покажет строку `TELEGRAM_CHAT_ID=...`, скопируйте её в `.env`.
   Можно указать несколько получателей через запятую, например вас и менеджера. Бота можно добавить и в группу: тогда напишите в группе любое сообщение и снова выполните `npm run chat-id`.
5. Проверка: `npm run test:telegram` — вам придёт тестовое сообщение.

## 2. Подключаем WhatsApp (ваш запасной номер)

### Вариант А — Green API (рекомендуется для запасного номера)

Ваш обычный номер подключается к WhatsApp так же, как WhatsApp Web, — через QR-код.

1. Вставьте SIM-карту с запасным номером в любой телефон и установите WhatsApp (лучше WhatsApp Business) на этот номер.
2. Зарегистрируйтесь на [green-api.com](https://green-api.com) и создайте инстанс.
3. В личном кабинете откройте инстанс и отсканируйте QR-код из WhatsApp на телефоне: «Связанные устройства» → «Привязка устройства».
4. Скопируйте данные инстанса в `.env`:
   ```
   WA_PROVIDER=greenapi
   GREEN_API_URL=https://api.green-api.com      # или apiUrl из кабинета
   GREEN_API_ID_INSTANCE=1101234567
   GREEN_API_TOKEN=abcdef0123456789...
   ```
5. Проверка: `npm run test:whatsapp -- 79991234567` (подставьте свой личный номер).

> ⚠️ WhatsApp может заблокировать номер, который массово пишет незнакомым людям. Здесь сообщения уходят только тем, кто сам ввёл номер на сайте, — это нормальный сценарий. Но не используйте номер для рассылок. Лучше, если номер какое-то время побудет «живым»: с перепиской и контактами. У Green API есть бесплатный тариф для разработки, но с ограничениями. Для работы с реальными клиентами нужен платный.

### Вариант Б — официальный WhatsApp Cloud API (Meta)

Подходит, если номер оформлен на бизнес в Meta Business. Для кодов нужен утверждённый шаблон категории **Authentication**.

```
WA_PROVIDER=meta
META_WA_TOKEN=...
META_WA_PHONE_NUMBER_ID=...
META_WA_OTP_TEMPLATE=имя_шаблона
META_WA_LANG=ru
```

## 3. Капча

Встроенный пазл проверяется на сервере: точность, время и траектория движения. Для серьёзной защиты от ботов подключите бесплатный [Cloudflare Turnstile](https://dash.cloudflare.com/?to=/:account/turnstile) — укажите `TURNSTILE_SITE_KEY` и `TURNSTILE_SECRET_KEY`. Капча заменится автоматически.

Ещё сервер ограничивает частоту запросов: регистрации с одного IP, отправку кода на один номер (не чаще раза в минуту, не больше 4 раз за сессию) и попытки ввода кода (5).

## Размещение в интернете

Сайту нужен работающий сервер: он отправляет коды и сообщения в Telegram. Подойдёт любой хостинг с Node.js.

- **VPS** (Timeweb, Selectel, Beget, Hetzner и т.п.): загрузите папку `stella`, создайте `.env` и запустите `npm start`. Чтобы сервер работал постоянно, используйте `pm2` (`npm i -g pm2 && pm2 start server.js --name stella`). Для HTTPS поставьте перед ним Nginx или Caddy.
- **Docker**: `docker build -t stella . && docker run -d -p 80:3000 --env-file .env stella`
- **Render / Railway**: подключите репозиторий, корневая папка — `stella`, команда запуска — `npm start`. Переменные из `.env` задайте в настройках сервиса.

Если открыть только `public/index.html` без сервера (например, через GitHub Pages), сайт заработает в **демо-режиме**. Анимации и регистрация будут работать, но сообщения никуда не уйдут — в окне регистрации появится предупреждение.

Если сайт и сервер на разных доменах, раскомментируйте в `index.html` строку `<meta name="stella-api" content="https://адрес-сервера">`. На сервере укажите `CORS_ORIGIN=https://адрес-сайта`.

## Что поменять под себя

- **Тексты, тарифы, кнопки** — `public/index.html`
- **Цвета** — переменные в начале `public/css/style.css` (`--violet`, `--cyan`, `--pink`, `--gold`)
- **Цены «Что заменяет STELLA»** (≈ $700 / мес и т.д.) — ориентировочные, поставьте актуальные для вашего рынка
- **Политика конфиденциальности** — блок `data-step="policy"` в `index.html`. Это шаблон: дополните реквизитами и контактами
- **Текст кода и подтверждения в WhatsApp** — `WA_OTP_TEXT` и `WA_ACK_TEXT` в `.env`
- **3D-сцена** (цвета ядра, число частиц, модели) — `public/js/scene.js`
- **Положение 3D-ядра по секциям** — объект `sceneKeyframes` в `public/js/main.js`

Оплата тарифов на сайте не подключена. Выбранный тариф приходит вам в Telegram, а инструкцию по оплате и запуску вы отправляете клиенту сами.

## Структура

```
stella/
├── server.js              сервер: страница + API регистрации
├── lib/
│   ├── env.js             чтение .env
│   ├── whatsapp.js        отправка кодов: console / Green API / Meta
│   └── telegram.js        уведомления в Telegram
├── tools/
│   ├── chat-id.js         npm run chat-id — узнать TELEGRAM_CHAT_ID
│   └── test-send.js       npm run test:telegram / test:whatsapp
├── public/
│   ├── index.html         страница и окно регистрации
│   ├── css/style.css      стили
│   └── js/
│       ├── scene.js       3D-сцена (Three.js)
│       ├── main.js        анимации, демо на телефоне, карусель
│       └── register.js    мастер регистрации
├── data/                  сюда сохраняются заявки (registrations.jsonl)
├── .env.example           пример настроек
└── Dockerfile
```

API сервера: `GET /api/config`, `POST /api/session`, `POST /api/captcha/challenge`, `POST /api/captcha/verify`, `POST /api/otp/send`, `POST /api/otp/verify`, `POST /api/agent`.
