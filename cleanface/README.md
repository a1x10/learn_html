# Cleanface — лендинг клининговой компании

Статичный сайт (HTML + CSS + JS, без сборки) для «Cleanface — Центр клининговых технологий», Алматы.
Тексты, цены, контакты и фотографии взяты с официального сайта компании (cleanface.kz).

## Запуск
Открыть `index.html` через любой локальный сервер, например:

```bash
cd cleanface && python3 -m http.server 8000
```

## Что внутри
- **Hero** — дом, сетка, анимация «слово за словом», видео-карточка с прогресс-барами, переключатель RU / EN.
- **Наши свежие объекты** — реальные фото с объектов, 3D-наклон карточек.
- **Сквиджи-сцена** — при прокрутке стеклоочиститель съезжает вниз и снимает капли со стекла (canvas + backdrop-filter).
- **Почему именно Cleanface** — 3D мыльные пузыри (three.js), 4 преимущества и сравнение «Cleanface против обычного подхода».
- **Все услуги** — 9 услуг с ценами; клик по услуге подставляет её в форму.
- **Как мы работаем**, **Репутация** (сертификат и письма с увеличением), **Контакты** с формой (открывает готовое письмо).

## Моушн-детали
- плавный скролл (Lenis, лежит локально в `assets/vendor`);
- свой курсор: на карточках, услугах и документах показывает подсказку («Смотреть», «Заказать», «Открыть»);
- магнитные кнопки и «перекатывающийся» текст на кнопках;
- плавающее меню, которое появляется при прокрутке вверх, и полоса прогресса страницы;
- вращающийся бейдж «Первые в Казахстане · Water Fed Pole» на первом экране, свечение за курсором;
- шторка-появление фото, счётчики цифр, кинетическая бегущая строка (ускоряется от скролла и меняет направление);
- «запотевшее стекло» — его можно протереть мышкой или пальцем (тап по стеклу — протирает целиком);
- буквы CLEANFACE в подвале заполняются при прокрутке и «подпрыгивают» под курсором;
- лёгкое плёночное зерно поверх страницы.

## Файлы
- `assets/css/style.css` — все стили и адаптив (десктоп / планшет / телефон)
- `assets/js/main.js` — анимации, переводы, услуги, видео, форма
- `assets/js/wipe.js` — сцена со стеклоочистителем
- `assets/js/bubbles.js` — 3D-пузыри (three.js из CDN)
- `assets/js/fx.js` — моушн-слой: скролл, курсор, магнитные кнопки, бегущая строка, счётчики, запотевшее стекло
