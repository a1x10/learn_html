FAQ

Questions, answered.

Is SQL Harmony free?

Yes. Create a free account to use the web app, and download the Windows desktop app at no cost.

What does it work with?

SQL Harmony is built for Oracle Fusion Cloud. You write SQL, or switch to PL/SQL mode, and run it against your Fusion instances.

Can I work with several instances?

Yes. Multi-instance support keeps environments like DEV, TEST and production one click apart in the same editor.

How does the AI assistance work?

The editor uses ChatGPT for query suggestions and error detection, so help arrives where you write instead of in another tab.

Can I export results to Excel?

Yes. Export results to XLSX, or to CSV in the desktop app, and bring data in from Excel when you need it.

What do I need for the desktop app?

Windows 10 or 11, 64-bit. The installer is 5.5 MB. You can sign in with Basic authentication or your identity provider's SSO.

Why does Windows warn me about the installer?

The installer isn't code-signed yet, so Windows shows "Windows protected your PC". Click More info, then Run anyway. You can compare the file's SHA-256 fingerprint with the one in the download section.
