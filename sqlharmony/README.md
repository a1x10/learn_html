# SQL Harmony — 3D-лендинг

Промо-сайт для [sqlharmony.com](https://sqlharmony.com/), бесплатного инструмента для SQL-запросов к Oracle Fusion (веб-версия и десктопная SQLHarmonyDesk для Windows). Вся графика — живое 3D в браузере (Three.js), анимации на GSAP, плавный скролл на Lenis. Сайт статический: `index.html` и папка `assets/`, сервер не нужен.

Тексты сайта на английском, как и на sqlharmony.com. Все факты взяты оттуда же: возможности, версия 0.5.0, размер 5.5 MB, дата выхода 2026-09-30, контрольные суммы SHA-256, ссылки на скачивание. Выдуманных цифр, отзывов и клиентов на сайте нет.

## Что на странице

| Блок | Что происходит |
|---|---|
| Прелоадер | Печатается `SELECT harmony FROM oracle_fusion;`, считаются «строки» и проценты, рисуется контур лисы. Затем восемь «строк»-шторок разъезжаются от центра |
| Первый экран | Лиса-талисман (как в favicon sqlharmony.com), собранная из 78 граней. При загрузке грани слетаются, лиса поворачивает голову за курсором. Вокруг вращается кольцо SQL-слов, спиралью втягивается поток частиц, внизу колышется «море» точек. При прокрутке лиса раскалывается, а осколки складываются в таблицу результатов: оранжевый заголовок, ячейки по две грани, некоторые подсвечиваются. Наведение на «Register free» раскачивает сцену |
| Бегущая строка | Две строки навстречу друг другу. Скорость и наклон зависят от скорости прокрутки |
| Манифест | Слова загораются по мере прокрутки, ключевые — оранжевым. Счётчики: цена «$0» отсчитывается вниз с $99, а 2, 5.5 MB и 2 формата считаются вверх |
| Возможности | Четыре карточки с отдельными 3D-сценами: копирование колонки, спираль истории запросов, хаотичные строки, которые «щёлкают» в отформатированный SQL, куб ячеек Excel. Карточки влетают в 3D, наклоняются за курсором с бликом. При наведении сцена ускоряется, по рамке бежит градиент |
| Редактор | Секция закрепляется на ~5 экранов прокрутки, и на макете редактора проигрывается работа в SQL Harmony. Запрос набирается с подсветкой синтаксиса, всплывает автодополнение колонок, открывается панель ChatGPT с подсказками, подчёркивается ошибка, появляется предложение ORDER BY. Затем нажимается Format, запрос переформатируется, Run выводит результаты, а файлы CSV и XLSX вылетают наружу. В конце открываются вкладки и папки и работает поиск. Слева прогресс по четырём шагам |
| Экземпляры | Хрустальное ядро, вокруг него кольцо кэша и четыре экземпляра Fusion (DEV, TEST, UAT, PROD). К активному экземпляру по лучу бегут пакеты данных. Экземпляры переключаются по кругу или кнопками |
| Видео | Рамка выпрямляется из наклона при прокрутке, кнопка с вращающейся надписью. YouTube загружается только по клику (youtube-nocookie) |
| Десктоп | 3D-ноутбук: при прокрутке открывается крышка, загорается экран с интерфейсом SQLHarmonyDesk, вокруг разлетаются файлы CSV/XLSX/SQL. Карточка загрузки с версией, ссылками на exe и zip, объяснением предупреждения Windows и копированием SHA-256 |
| Призыв | Концентрические «гармонические» кольца с волнами. Реагируют на курсор и «звучат» громче при наведении на кнопки |
| Подвал | Контур надписи «SQL Harmony» заливается градиентом при прокрутке |

Везде работают: свой курсор с подписями («Play», «Explore»), световое пятно за курсором, «магнитные» кнопки, у которых заливка расходится из точки под курсором, и «расшифровка» пунктов меню при наведении. Фон плавно меняет цвет между секциями, по экрану медленно дрейфует «аврора» и лежит зерно. Шапка прячется при прокрутке вниз, сверху индикатор прогресса. На мобильных — меню-шторка.

## Что можно поменять

| Что | Где |
|---|---|
| Ссылки (регистрация, вход, скачивание exe/zip, LinkedIn) | `src/config.js`. В `index.html` стоят те же адреса как запасной вариант |
| Тексты | `index.html` |
| Версия, размер, дата, хеши SHA-256 десктопа | `index.html`, блок `.dcard` |
| Цвета | Токены в начале `src/styles/main.css` (`--fox`, `--indigo`, `--grad` и др.) |
| Видео | `index.html`, атрибут `data-video` (ID ролика на YouTube) |
| Интерфейс на экране 3D-ноутбука | `src/three/textures.js` → `screenTexture()` |
| Запрос в макете редактора | `src/sections/editor.js` → `RAW` (до форматирования) и `FORMATTED` (после) |

После правок в `src/` пересоберите сайт. Если правили только `index.html`, пересборка не нужна.

**Регистрация и вход.** На sqlharmony.com они открываются окнами на главной странице, отдельного адреса у них нет. Поэтому кнопки «Register free» и «Log in» ведут на `https://sqlharmony.com/`. Если появятся отдельные страницы, поменяйте адреса в `src/config.js`.

## Как запустить и собрать

Нужен Node.js 18+.

```bash
cd sqlharmony
npm install          # один раз
npm run build        # собирает assets/app.js и assets/app.css
npm run dev          # пересборка при изменениях
python3 -m http.server 8080   # открыть http://localhost:8080
```

Команда `node build.mjs --artifact` дополнительно собирает один самодостаточный файл `dist/sqlharmony-artifact.html`. В него встроено всё, кроме шрифтов Google Fonts и обложки видео.

## Как выложить

Через GitHub Pages, как и соседний проект: после попадания в ветку `main` сайт будет по адресу **https://a1x10.github.io/learn_html/sqlharmony/**. На этот адрес уже настроены мета-теги превью (`og:url`, `og:image`). При переезде на свой домен поменяйте их в `index.html`.

Подойдёт любой статический хостинг: загрузите `index.html` и папку `assets/`.

## Производительность и доступность

- Одна WebGL-канва на всю страницу: каждая 3D-сцена рисуется только в своём блоке и только когда он на экране.
- Если кадры долгие, плотность пикселей снижается автоматически. На телефонах частиц меньше.
- Шейдеры компилируются во время прелоадера, поэтому при прокрутке нет подвисаний.
- При включённой в системе настройке «уменьшить движение» сайт показывается без закреплений и анимаций, все блоки видны сразу.
- Если браузер не поддерживает WebGL, вместо 3D показываются SVG-лиса и иконки, весь контент на месте.
- Один H1, навигация с клавиатуры, видимый фокус, `aria`-атрибуты у меню и переключателей.

## Структура

```
index.html               страница и все тексты
assets/                  собранные app.js и app.css, favicon, картинка-превью og-cover.jpg
build.mjs                сборка (esbuild)
src/config.js            ссылки
src/main.js              запуск: прелоадер, 3D, анимации
src/styles/main.css      стили и цветовые токены
src/three/               3D: движок (одна канва, сцены по блокам), окружение, текстуры
  fox.js                 лиса из граней и шейдер «осколки → таблица»
  stages/                сцены: первый экран, карточки, экземпляры, ноутбук, кольца
src/sections/            сценарии прокрутки: первый экран, редактор, остальное
src/ui/                  курсор, шапка, прелоадер, появление, бегущая строка, виджеты
```
