# SQL Harmony — 3D-лендинг

Лендинг для [sqlharmony.com](https://sqlharmony.com/) — бесплатного SQL-редактора для Oracle Fusion Cloud (веб-приложение и десктоп-версия SQLHarmonyDesk для Windows). Почти вся графика — живое 3D в браузере (Three.js), анимации на GSAP, плавный скролл на Lenis. Сайт статический: `index.html` + папка `assets/`, сервер не нужен.

Тексты сайта на английском, как у продукта. Все факты взяты с sqlharmony.com и sqlharmony.com/desktop: возможности, версия 0.5.0, 5,5 МБ, Windows 10/11, SHA-256 установщика, ссылки на регистрацию, загрузку и LinkedIn разработчика. Отзывов, цифр пользователей и цен нет — их на исходном сайте тоже нет, поэтому они не придуманы.

## Что на странице

| Блок | Что происходит |
|---|---|
| Прелоадер | Граненый лис рисуется линиями ребро за ребром, печатается `SELECT harmony FROM oracle_fusion;`, счетчик до 100. Потом грани заливаются цветом и экран раскрывается шторками |
| Первый экран | 3D-лис (маскот SQL Harmony) собирается из ~1 700 осколков, которые прилетают из-за камеры. Голова поворачивается за курсором, грани возле курсора приподнимаются. За лисом — гигантское слово HARMONY (контур, под курсором заливается светом и рябит), вокруг летают SQL-слова, внизу «гармонические» волны света. При скролле лис разлетается на осколки, а заголовок растворяется |
| Зачем | Текст загорается по словам по мере прокрутки, ключевые слова подчеркиваются |
| Workbench | Окно веб-приложения (повторяет реальный интерфейс: Run SQL, инстансы, вкладки, Submit, fix, PLSQL, format, cols, xlsx, Parameters, History) выпрямляется из перспективы, SQL-запрос к `ap_invoices_all` печатается, Submit, строки результата падают в таблицу, две колонки копируются, результат экспортируется в xlsx. Выноски показывают функции. Осколки лиса летают кольцом вокруг окна |
| Кольцо | Два встречно вращающихся 3D-кольца из текста (SQL-команды и факты о продукте); скорость зависит от скорости скролла. Ниже — бегущая строка с наклоном по скорости |
| Функции | Горизонтальная галерея из 4 карточек с 3D-перспективой. Осколки лиса складываются в иконку текущей функции (два листа, часы, отформатированный код, таблица). В каждой карточке своя живая демонстрация: копирование колонки, поиск по истории, форматирование запроса (токены перелетают на свои места), экспорт в Excel |
| AI | Жидкая переливающаяся сфера (шум в шейдере), вокруг нее сфера из осколков. Демо: ошибка ORA-00904 → кнопка fix → ChatGPT объясняет → исправление применяется, сфера вспыхивает зеленым |
| Инстансы | Созвездие: SQL Harmony в центре, DEV1/DEV2/TEST/UAT/PROD вокруг, по дугам бегут пакеты света; осколки образуют спиральную галактику. Вкладки переключают активный инстанс |
| Редактор | 3D-клавиши печатают S-Q-L и нажимают оранжевую RUN; клавиша под курсором нажимается. Карточки наклоняются за курсором |
| Десктоп | 3D-ноутбук: крышка открывается при скролле, экран включается и показывает живой интерфейс SQLHarmonyDesk (таблицы и колонки, автодополнение, страницы результатов, SSO). Карточка загрузки с версией, ссылкой на zip, предупреждением SmartScreen и SHA-256 с кнопкой «Copy» |
| Видео | Скриншот приложения в 3D-рамке, кнопка с пульсом; по клику — YouTube-ролик во всплывающем окне |
| Факты | Счетчики: $0, 5.5 MB, CSV · XLSX, Basic · SSO |
| FAQ | Плавное раскрытие ответов |
| Финал | Осколки снова собираются в лиса, вокруг вращаются световые кольца и лучи |
| Подвал | Огромная надпись SQL Harmony, буквы поднимаются и «тянутся» к курсору. Дисклеймер о товарных знаках Oracle |

Везде: кастомный курсор, магнитные кнопки с бликом и «перекатом» текста, плавная смена освещения неба между секциями, свет за курсором, хроматическая аберрация при быстром скролле, зерно пленки, шапка прячется при скролле вниз, индикатор прогресса и боковая шкала с названием секции, включаемый фоновый звук (аккорд синтезируется в браузере, файлов нет).

| Что | Где |
|---|---|
| Ссылки «Create free account / Log in» | `index.html`, адрес `https://sqlharmony.com/` |
| Новая версия десктопа | `index.html`, блок `#download`: номер версии, размер, ссылки `desktop/dl/exe` и `desktop/dl/zip`, обе SHA-256 (в тексте и в `data-copy`), имя файла в команде `Get-FileHash`. Размер еще в блоке фактов (`data-count="5.5"`) и в FAQ |
| Видео | `index.html`, атрибут `data-video` и ссылка у `.video` |
| Тексты | `index.html` |
| Цвета | токены в начале `src/styles/main.css` |
| Лис (форма, цвета граней) | `src/gl/fox.js` — точки `P`, грани `FACES`, цвета `FOX_COLORS`. Логотип и иконка генерируются из той же модели при сборке |

После правок в `src/` пересоберите сайт. Правки только в `index.html` пересборки не требуют.

## Как запустить и собрать

Нужен Node.js 18+.

```bash
cd sqlharmony
npm install          # один раз
npm run build        # assets/app.js, assets/app.css, логотип и favicon
npm run dev          # пересборка при изменениях
python3 -m http.server 8080   # открыть http://localhost:8080
```

`npm run artifact` дополнительно собирает один самодостаточный файл `dist/sqlharmony.html` (всё встроено, кроме шрифтов Google Fonts).

## Как выложить

Через GitHub Pages сайт будет по адресу **https://a1x10.github.io/learn_html/sqlharmony/** — после слияния в `main` (Pages уже включены для репозитория). Подойдет и любой статический хостинг: загрузите `index.html` и папку `assets/`. При переезде на свой домен поменяйте адрес в мета-тегах `og:url` и `og:image`.

## Производительность и доступность

- Одна WebGL-канва на всю страницу; каждый 3D-объект привязан к своему блоку и рисуется только когда блок на экране.
- Если кадры долгие, сначала снижается плотность пикселей, затем отключается свечение (bloom). На телефонах меньше частиц и нет bloom.
- Шейдеры компилируются во время прелоадера.
- При системной настройке «уменьшить движение» — без закреплений, скролл-анимаций и звука, весь текст сразу виден.
- Без WebGL вместо 3D показывается плоский логотип-лис, весь контент на месте. Без JavaScript страница тоже читается.
- Навигация с клавиатуры, видимый фокус, `aria`-атрибуты у меню, вкладок, видео и звука.

## Структура

```
index.html               страница и все тексты
assets/app.js, app.css   собранные файлы (их и выкладываем)
assets/img/              скриншот приложения, логотип (генерируется)
build.mjs                сборка (esbuild)
scripts/mark.mjs         логотип и favicon из 3D-модели лиса
src/main.js              запуск: прелоадер, 3D, анимации
src/styles/main.css      стили и цветовые токены
src/gl/                  3D: мир и постобработка, лис и осколки, формации, небо,
                         кольца текста, AI-сфера, созвездие, клавиши, ноутбук, портал
src/sections/            сценарии секций и «режиссер» осколков
src/ui/                  курсор, навигация, текстовые эффекты, виджеты, звук
```
