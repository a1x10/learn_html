# Алексей — портфолио

Сайт-портфолио в стиле первого экрана из `../goods-store`: React + TypeScript + Vite + Tailwind CSS 4, иконки lucide-react.

## Что на странице

- **Первый экран** — огромное «АЛЕКСЕЙ, 13 ЛЕТ» во всю ширину, перед буквами парит фото с мягкой тенью; стеклянная шапка с меню, «о себе» с кнопкой в Telegram, карточка навыков.
- **Бірлік** — школьная учебная система: цифры, три рабочих места, цикл «учитель → ученик → сервер → журнал → профиль», безопасность, техника и бизнес.
- **Stells Pro** — языковая модель: проблема, как работает, устройство и слои, преимущества, монетизация.
- **Stella Coder** — ИИ-помощник программиста: интерфейсы, возможности, модели, файлы, стек, сценарии.
- **Связаться** — Telegram @l3xn0.

## Где что менять

| Что | Где |
|---|---|
| Тексты проектов, Telegram | `src/content.ts` |
| Заголовок первого экрана, «о себе», кнопка, цвет карточки | константы в начале `src/Hero.tsx` |
| Фото | `src/assets/alexey.webp` (прозрачный фон), `src/assets/avatar.webp` (лицо для кнопки) |
| Цвета и шрифты | `src/index.css` |

Фото вырезано из исходного снимка на сером фоне `#B3B5B9` — этот же цвет у карточки первого экрана. Если меняете фото, нужен PNG/WebP с прозрачным фоном, а `CARD_BG` — под цвет фона снимка.

## Как устроены размеры

- Первый экран: 1 единица Tailwind = u = min(100vw / 1440, 100vh / 900), то есть `h-64` — это 64u.
- Секции проектов (`.flow`): 1 единица = 100vw / 1440 (от 0.8 до 1.25px), на телефоне ровно 1px.
- Мобильная раскладка — ширина меньше 760px или портретная ориентация, вариант `mob:`.
- Крупные заголовки проектов растягиваются на всю ширину блока (`FitText` в `src/fit.tsx`): кегль считается через `canvas.measureText` после загрузки шрифта, межбуквенный интервал не меняется.

## Запуск

```bash
npm install
npm run dev       # разработка
npm run build     # сборка в dist/
npm run preview   # посмотреть сборку
```

Собранная версия лежит в `dist/` (пути относительные). После слияния в `main` она будет на GitHub Pages: https://a1x10.github.io/learn_html/alexey/dist/
