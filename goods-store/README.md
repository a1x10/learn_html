# goods. — первый экран магазина одного товара

React + TypeScript + Vite + Tailwind CSS 4, иконки lucide-react. Весь экран — компонент `src/Hero.tsx`.

## Как поменять товар

Константы в начале `src/Hero.tsx`:

| Константа | Что это |
|---|---|
| `PRODUCT_WORD` | огромный заголовок (сам растягивается на ширину карточки) |
| `DESCRIPTION` | текст внизу слева |
| `PRICE` | цена в кнопке; пустая строка — цены нет, текст кнопки по центру |
| `BUTTON` | текст кнопки |
| `PRODUCT_IMAGE` | PNG с прозрачным фоном |
| `PRODUCT_ALT` | описание картинки для скринридеров |
| `CARD_BG` | цвет карточки — возьмите цвет фона фото товара |

## Как устроена раскладка

- Все размеры десктопа взяты из макета 1440×900 и масштабируются единицей `u = min(100vw / 1440, 100vh / 900)`. В Tailwind это шаг отступов: `h-64` = 64u (см. `src/index.css`).
- Мобильная раскладка (ширина < 760px или портретная ориентация) — вариант `mob:`.
- Кегль заголовка, положение товара и тени считает JS (`computeLayout`) после загрузки шрифта и картинки и при каждом изменении размера: заголовок занимает всю ширину карточки, но не доходит до нижних блоков, товар закрывает ~40% высоты прописных букв (на мобильных ~35%) и не заходит на блоки.

## Запуск

```bash
npm install
npm run dev       # разработка
npm run build     # сборка в dist/
npm run preview   # посмотреть сборку
```

Собранная версия лежит в `dist/` (пути относительные), её можно выложить на любой статический хостинг. После слияния в `main` она будет на GitHub Pages: https://a1x10.github.io/learn_html/goods-store/dist/
