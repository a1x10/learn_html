# Портфолио Алексея

Одностраничный сайт-портфолио в светлом стиле Apple: 3D-сцены на Three.js, анимации при скролле (GSAP + ScrollTrigger) и плавная прокрутка (Lenis).

## Как открыть

- Просто откройте `index.html` в браузере (нужен интернет, потому что библиотеки и шрифты грузятся с CDN).
- Или запустите локальный сервер из этой папки: `npx serve .` либо `python3 -m http.server`.

## Что внутри

| Секция | Что происходит |
| --- | --- |
| Hero | Живая перламутровая 3D-форма (шейдер с шумом), жемчужины на орбитах, реакция на мышь и скролл |
| Обо мне | Текст подсвечивается по словам при прокрутке |
| Цифры и бегущая строка | Счётчики; скорость строки зависит от скорости скролла |
| Бірлік | 3D-карусель предметов, устройство превращается из телефона ученика в портал учителя и админку владельца, анимированная схема «по кругу», горизонтальная лента возможностей |
| Stells Pro | Закреплённая 3D-нейросеть (слои, связи, бегущие сигналы, кнопка «Отправить сигнал», вращение мышью), демо механизма внимания, анатомия нейрона, «думающая» консоль |
| Stella Coder | 3D-сцена из редактора, терминала и телефона: код набирается, ИИ находит ошибку и применяет патч; орбита моделей |
| Навыки | 3D-сфера технологий и шкалы языков |
| Контакт | Магнитные кнопки на анимированном фоне |

## Структура

```
portfolio/
├── index.html      — разметка и контент
├── css/style.css   — стили и адаптив
└── js/
    ├── main.js     — скролл, появление блоков, демо-анимации, курсор
    ├── hero.js     — 3D-сцена первого экрана
    └── neural.js   — 3D-нейросеть Stells Pro
```

## Перед публикацией

- Замените контакты в секции «Связаться» (`index.html`, ищите `TODO`): сейчас там `hello@example.com` и пустые ссылки на Telegram и GitHub.
- Имена учеников, цифры в макетах экранов, строки терминала и консоли — демонстрационные, их можно поменять под реальные.

## Публикация

Проще всего через GitHub Pages: Settings → Pages → ветка с этой папкой. Сайт будет доступен по адресу вида `https://<логин>.github.io/learn_html/portfolio/`.

Учтены `prefers-reduced-motion` (анимации отключаются) и сенсорные экраны (кастомный курсор и наклоны не мешают).
